## Kill patterns

- Binary contrasts: "Not X. Y."
- Dual CTAs in one hero
- Vague headlines: "Small tools. Large reach."
- Defensive lines: "Products, not empty portfolio cards."
- Empty manifesto: "Build something that belongs in the world."
- SaaS filler: "Everything you need. Nothing you don't."
- Throat-clearing, adverbs, em dashes, staccato punch lines

## Keep

- Brand marks (Ordani + TinyMe)
- World stills + hex as hero object
- Sample-data labels
- One primary CTA per surface

## TinyMe scroll rules (session lock)

- **One film only** (`/assets/world/film/tinyme-world.mp4`). Scroll scrubs it. No 6-plate carousel.
- **3 beats max.** No VOID / SIGNAL / EVENT / 05–06 chrome.
- **Banned ad copy:** signal, know what clicked, people vs bots, route each click, feature-tag lists, custom domains claims, dual CTAs.
- **Allowed spine:** Little link. Big features. → Print it once. → Swap the destination. → **Make a link.**
- End screen: single gold CTA only.
