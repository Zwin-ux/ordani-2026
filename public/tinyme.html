02Features

What ships in the product

Core capabilities. No filler list.

↗

Editable destinations

Change where a link points without reprinting, re-sharing, or losing a single click. Destination history and one-click rollback included.

  • Destination history
  • One-click rollback
  • Backup destinations
◆

Routing rules

Send different visitors to different destinations based on country, device, schedule, or weight. Fallback destinations handle the rest.

  • Country / region
  • Device type
  • Scheduled
  • Weighted
◎

Privacy-aware analytics

Human clicks, bots, referrers, devices, coarse geography, latency — all separated and honest. No fake totals. No surveillance.

  • Human vs bot
  • Coarse geography
  • Referrer tracking
  • Latency metrics
▣

Custom domains

Bring a branded short domain when that path ships. DNS and HTTPS setup are the intended direction — not live self-serve yet.

  • Direction
  • DNS + HTTPS
  • Branded host
⊞

QR codes

Generate QR codes for any link. Download as PNG or SVG. Include your brand colors. Track QR-specific scans separately.

  • PNG + SVG
  • Brand colors
  • Scan tracking
⊡

Protection

Password-protect links, set expiration dates, and limit total clicks. Expired links show a configurable landing page.

  • Password
  • Expiration
  • Click limits
⊟

Tags and organization

Tags, folders, and workspaces keep hundreds of links organized. Filter by tag, domain, status, or date range.

  • Tags
  • Folders
  • Workspaces
△

Destination health

Monitor whether your destination is actually reachable. Get alerted when response times spike or pages start returning errors.

  • Uptime checks
  • Response time
  • Error alerts

06Product model

Four objects keep the product understandable.

Everything TinyMe does maps to a Link, Destination, Rule, or Event.

01 / Link

The permanent public address.

The slug, domain, owner, state, tags, protection, limits, and expiration.

lnk
02 / Destination

Where it resolves now.

A current target with health state, history, rollback, and backup behavior.

dst
03 / Rule

Who goes where and when.

Country, device, schedule, weight, deep-link, and fallback conditions.

rul
04 / Event

What happened on access.

A privacy-aware record of request type, route, timing, and coarse context.

evt
07Developer API

Full API access. Your links, your apps.

REST API and webhooks to create, manage, and track links directly from your own tools.

Create a link POST /api/links 
curl -X POST https://api.tinyme.cc/v1/links \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "domain": "tinyme.cc",
    "slug": "summer",
    "destination": "https://store.example.com/summer-2026",
    "tags": ["campaign", "summer"]
  }'
201 Created
